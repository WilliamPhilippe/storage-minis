# Triage labels

The engineering skills use five canonical triage roles. Map each role to the GitHub label below.

| Role in the skills | Label in this tracker | Meaning |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | Maintainer needs to evaluate this issue. |
| `needs-info` | `needs-info` | Waiting on the reporter for more information. |
| `ready-for-agent` | `ready-for-agent` | Fully specified and ready for an autonomous agent. |
| `ready-for-human` | `ready-for-human` | Requires human implementation or judgment. |
| `wontfix` | `wontfix` | Will not be actioned. |

When a skill mentions a role, use the corresponding label from this table. Existing `kind:*`, `area:*`, `spec:*` and `blocked` labels retain their separate meanings; a triage readiness label does not resolve a dependency or approve an open policy.
