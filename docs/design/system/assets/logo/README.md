# App Logo

- `storageminis-logo.png`: the full logo, transparent and trimmed to the artwork. Use it in the UI: phone `TopBar` at 20px tall, expanded `SideNav` at 20px, sign-in page at 28px.
- `storageminis-mark.png`: the drawer-and-car mark alone, transparent and trimmed. Use it in the collapsed `SideNav` at 32px wide, and for favicons and app icons.
- `storageminis-logo-original-transparent.png`, `storageminis-logo-original-white.png`: the originals as supplied, with wide margins. Keep them for print and partners.

The inks are black and racing red (`#ba0101`), so place the logo only on light grounds (`surface`, `surface-page`).
